# Priyanka Yadav – 3D Portfolio (React + Vite + Bootstrap 5)

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```
## Customize
- Content & placeholder images: `src/data.js`
- Colors / theme tokens: top of `src/styles/global.css`
- Add `public/resume.pdf` for the Download Resume button
- Replace `example.com`, email, LinkedIn, GitHub and WhatsApp placeholders (index.html, Contact.jsx, Footer.jsx, sitemap.xml, robots.txt)
- Contact form backend: see the comment in `Contact.jsx` submit handler
